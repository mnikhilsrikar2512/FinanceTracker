FAQ

Frequently asked questions

These cover the questions most new users and admins run into first.

Why do I land on login when I open the app link?
Public visitors should start from the landing page. Protected pages like dashboard, transactions, reports, and admin tools redirect to login if there is no valid session. Use Get Started if you are new, or Log In if your account already exists.
How does forgot password work?
First enter your email on Forgot Password. If the account exists, Finly sends a 6-digit verification code. Then move to the reset step, enter the same email, add the code, and choose a new password that matches the current password rules.
Why can’t I see admin pages?
Admin pages only appear for accounts with the admin role. Regular users will see personal pages like dashboard, transactions, reports, budgets, notifications, and profile instead of system users, logs, or platform transactions.
What is the difference between archive and delete?
Archive hides a transaction from normal views but keeps it available for history and restore actions. Delete removes it permanently. For most cleanup tasks, archive is the safer option.
Why are my reports different from admin reports?
User reports show personal spending, category mix, and monthly trends for one account. Admin reports show a platform-wide summary across users, including user activity and system transaction behavior for the selected date range.
What details should I send when reporting an issue?
Send the page name, what you clicked, the time it happened, your account email, and ideally a screenshot. If it involves exports, attach the PDF or CSV. If it involves filters, mention the selected date range and archive state.
Workspace Guide

Understand the two main experiences

User workspace

Personal finance tools

  • Dashboard: quick view of balance, spending, and budget health.
  • Transactions: add, edit, archive, restore, filter, and export your money history.
  • Reports: understand trends, top categories, and monthly movement.
  • Budgets: compare spending against category limits over time.
Admin workspace

System oversight

  • Admin dashboard: check high-level user and transaction health.
  • User management: review, inspect, block, or unblock accounts.
  • System transactions: audit platform entries and run bulk archive or restore actions.
  • Operation logs: trace important events and investigate issues.
